# 复审说明：数字模式完整语义已纳入项目目标

## 1. 对驳回意见的逐项处理

原驳回意见指出：申报终点排除了完整 CLDR 数字模式语法和舍入增量等核心语义。
本次修改已删除该排除表述，并把相应语义纳入 0.1.x 的数字格式化目标与测试终点：

| 驳回关注点 | 本次处理 | 代码位置 |
| --- | --- | --- |
| 完整数字模式语法 | 支持 `0/#` 固定位、`@/#` 有效位、`1-9` 增量、`.`/`,`、`E`、`+`/`-`、`%`/`‰`、`¤`、单引号、`*` 填充与 `;` 正负子模式 | `number/pattern.mbt`、`pattern/tokenizer.mbt` |
| 舍入增量 | 按 `1-9` 在模式中的位置计算增量，采用 half-away-from-zero；固定小数位、有效位和科学计数法尾数共用该舍入实现 | `decimal/decimal.mbt`、`number/format.mbt` |
| 有效位 | `@` 的个数为最小有效位，后续 `#` 扩展最大有效位；支持整数侧和小数侧舍入 | `number/format.mbt` |
| 验收范围不明确 | 在符合性文档新增数字模式验收矩阵与案例，并由测试和机器校验脚本固定 | `docs/conformance.md` 第 3.3.1 节、`tools/check-conformance.mjs` |

## 2. 有效位验收案例

以下案例均可通过 `moon test number` 复核：

| 模式与输入 | 输出 | 验收点 |
| --- | --- | --- |
| `@@@` + `1.0` | `1.00` | 固定 3 位有效位 |
| `@@@` + `0.12345` | `0.123` | 小数侧有效位舍入 |
| `@@@` + `1234.56` | `1230` | 整数侧有效位舍入 |
| `@@##` + `1.0` | `1.0` | 最小 2 位有效位 |
| `@@##` + `0.12345` | `0.1235` | 最大 4 位有效位 |

## 3. 增量舍入验收案例

| 模式与输入 | 输出 | 验收点 |
| --- | --- | --- |
| `0.05` + `1.22` | `1.20` | 向最近的 0.05 下舍 |
| `0.05` + `1.23` | `1.25` | 向最近的 0.05 上舍 |
| `0.05` + `1.225` | `1.25` | 中点 half-away-from-zero |
| `0.005` + `1.23456` | `1.235` | 千分位增量 |
| `#,##0.05` + `1234.56` | `1,234.55` | 增量与分组组合 |
| `0.05E0` + `1234.56` | `1.25E3` | 科学计数法尾数增量 |
| `0.25` + `1.15` | `1.25` | 两个非零增量位共同组成 0.25 |
| `0.25` + `1.24` | `1.25` | 按完整增量 0.25 上舍 |
| `*_#,##0.00` + `1.2` | `____1.20` | 按模式完整宽度填充 |
| `*_$#,##0.00` + `1.2` | `$____1.20` | 填充插入在前缀之后 |
| `*_#,##0.00;(#,##0.00)` + `-12.3` | `(_12.30)` | 负子模式使用正子模式宽度 |

`0.25` 同时验证多个非零增量位按位置合并，避免把模式误解析为仅按末位
`5` 舍入；整数位、小数位与科学计数法尾数共用同一增量。

引号语义同时覆盖百分号和货币占位符：`'%'` 不缩放、不本地化，`'¤'` 保持
字面货币占位符，只有引号外的标记参与格式化。

## 5. 修订后的项目目标表述

moonl10n 在 CLDR 48 / UTS #35 revision 48 基线上实现面向 MoonBit 的本地化格式化内核。
数字格式化覆盖固定小数位与有效位两条 CLDR 数字模式分支，包括 `@` 有效位、`1-9`
增量舍入、科学计数法、百分比/千分比缩放、货币标记、分组、引号字面量、填充和正负子模式；
其验收范围由 `docs/conformance.md` 第 3.3.1 节的案例与 `number/format_wbtest.mbt`
的断言共同固定。
